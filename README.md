## What TORANG is

TORANG is an offline AI assistant for business dashboards. It sits inside Microsoft Power BI as a custom visual,
answers questions about the dashboard's data in English and Persian, explains why numbers changed, forecasts the
coming weeks, and exports meeting-ready PowerPoint and PDF reports. Everything runs on the user's own computer,
so no data leaves the organisation.

The name comes from *Tazarv* (تذرو), the Persian word for the pheasant.

## What this repository is

This repository holds **proof of authorship only**. It contains no source code, no design documents and no
description of how TORANG works.

Each file in the `proofs` folder is a dated fingerprint (SHA-256 hash) of the complete TORANG source code and
design documents as they stood on that date. A fingerprint cannot be turned back into the files, but anyone holding
the original files can recompute it and check that it matches. The `.ots` file next to each fingerprint is an
OpenTimestamps proof that anchors the fingerprint in the Bitcoin blockchain, so its date cannot be changed later.
Verify it at https://opentimestamps.org.
